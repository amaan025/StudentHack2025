# 📈 Portfolio Recommendation System — StudentHack 2025

A data-driven, resilient portfolio allocation system developed for real-time US equities analysis.  
This project generates personalised investment portfolios based on client profiles, live market data, and risk appetite.

Built to simulate production environments with robust error handling, logging, and modular architecture.

---

## 🚀 Features

- ✅ **Automated Portfolio Recommendation**  
  Based on user-specific inputs like age, salary, budget, and sector preferences.

- ✅ **Real-time Market Data Integration**  
  Using Yahoo Finance API for dynamic pricing and stock information.

- ✅ **Risk Assessment**  
  Calculates a Risk Tolerance Score (RTS) based on user profile and market volatility.

- ✅ **Resilient API Requests**  
  Implemented retry logic and safe failover mechanisms.

- ✅ **Modular Design & Logging**  
  Clean separation of concerns across files with comprehensive logging.

---

## 🛠️ Tech Stack

- Python 3.9+
- pandas, numpy
- yfinance (Market data)
- requests, tenacity (Resilient API calls)
- Logging module for observability
